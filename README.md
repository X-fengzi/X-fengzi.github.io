# XFENGZI 创作档案

一个使用 Astro、Markdown/MDX 和 GitHub Pages 构建的个人创作博客。

## 栏目

- 创作：设计、插画、摄影、程序作品与实验
- 文章：长文、创作过程与思考
- 片段：灵感、短笔记和碎片
- 专题：围绕一个主题持续更新的系列
- 关于：个人介绍与联系方式

## 本地预览

```sh
npm install
npm run dev
```

构建正式版本：

```sh
npm run build
```

内容写作与发布方式参见 [CONTENT_GUIDE.md](./CONTENT_GUIDE.md)。

## GitHub Pages

仓库命名为 `X-fengzi.github.io`。推送到 `main` 后，在仓库 Settings → Pages 中将 Source 选择为 GitHub Actions，工作流会自动发布到 `https://x-fengzi.github.io/`。
